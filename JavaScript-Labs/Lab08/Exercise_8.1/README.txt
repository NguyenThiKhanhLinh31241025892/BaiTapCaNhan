Exercise 8.1 — Enabling/Disabling JavaScript

PDF yêu cầu kiểm tra URL: http://examples.funwebdev.com/JavaScriptTest.php
Mở URL với JavaScript bật và tắt; chụp hai trạng thái.
Nếu website mẫu đã ngừng hoạt động, sử dụng js-test-fallback.html CHỈ để minh họa nguyên lý, và ghi rõ đây là trang thay thế thử nghiệm cục bộ, không phải URL trong PDF.
Tự chụp bằng trình duyệt của bạn để có bằng chứng xác thực.
